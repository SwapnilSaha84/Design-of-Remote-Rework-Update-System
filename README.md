# Design-of-Remote-Rework-Update-System
Designed and implemented a wireless communication system using NRF24L01 modules for real-time updates between workers and debugging engineers. Built transmitter/receiver using Arduino Uno with 12V–3.3V regulation, LEDs, and buzzer. Implemented states: Free (Blue), Assigned (Red), In-progress (Yellow), Completed (Green+buzzer). Tested on hardware .
